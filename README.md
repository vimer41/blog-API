# Modsen Blog API

Backend-приложение для ведения блога Modsen.

## Технологический стек
- **Фреймворк:** NestJS
- **База данных:** PostgreSQL
- **ORM:** Prisma
- **Авторизация:** PassportJS (JWT: Access + Refresh токены)
- **Документация:** Swagger (OpenAPI)
- **Контейнеризация:** Docker & Docker Compose
- **Процесс разработки:** ESLint, Prettier, Husky, Conventional Commits

## Основные возможности (Функционал)
- **Ролевая модель:** Admin (полный доступ), User (управление своими ресурсами), Reader (только чтение и лайки).
- **Посты:** CRUD операции, пагинация, фильтрация по автору/заголовку/дате, сортировка по количеству лайков и дате создания.
- **Комментарии:** CRUD операции, привязка к постам.
- **Реакции:** Возможность ставить лайки на посты (1 пользователь = 1 лайк на пост).
- **Безопасность:** Глобальная обработка ошибок в едином JSON формате, валидация входящих данных (`class-validator`, `class-transformer`).

## Запуск проекта

Убедитесь, что у вас установлены Docker и Docker Compose.

1. Склонируйте репозиторий:
   ```bash
   git clone [ссылка на твой репо]
   cd modsen-blog

2. Создайте .env файл в корне проекта, пример, .env.example
3. Запустите проект в docker контейнере
    ```bash
   docker-compose up --build
   ```
