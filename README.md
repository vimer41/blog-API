# Blog API

Backend-приложение для ведения блога Modsen.

## Технологический стек
- **Фреймворк:** NestJS
- **База данных:** PostgreSQL
- **ORM:** Prisma
- **Авторизация:** PassportJS (JWT Access + Refresh токены)
- **Документация:** Swagger (OpenAPI)
- **Контейнеризация:** Docker & Docker Compose
- **Процесс разработки:** ESLint, Prettier, Husky, Conventional Commits

## Основные возможности
- ***Аутентификация и пользователи:***
  - Регистрация новых пользователей и безопасный вход.
  - Управление доступом через роли


- ***Работа с постами:***
  - Создание новых публикаций.
  - Редактирование и удаление свих постов.
  - Просмотр ленты постов (доступно всем).
  - Пагинация, удобная фильтрация (по автору, заголовку, дате) и сортировка (по дате или количеству лайков).


- **Комментарии:***
   - Возможность оставлять комментарии под любыми постами.
   - Редактирование и удаление собственных комментариев.
   - Автоматическое удаление комментариев при удалении поста.


- ***Лайки:***
   - Поставить и убрать лайка на пост, один пользователь может поставить только один лайк.
   - Просмотр общего количества лайков у каждого поста.

## Запуск проекта

Убедитесь, что у вас установлены Docker и Docker Compose.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/vimer41/blog-API
   cd blog-API
   ```

2. Создайте .env файл в корне проекта, пример, .env.example
3. Запустите проект в docker контейнере
    ```bash
   docker-compose up --build
   ```
Далее после запуска контейнера автоматически применится миграции БД и будет создан пользователь с ролью Администратора, с username, email, passwordHash тем который вы указали в .env

4. Отройте документацию swagger: http://localhost:3000/api
